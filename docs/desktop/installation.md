# Installation
Hana Desktop is currently available for Mac, Linux and Windows.

## Mac
The easiest and best way to install Hana on Mac is through [App Store](https://apps.apple.com/). Alternatively, you can find the .dmg on the [Downloads](https://hanassh.com/download) page.

## Linux
There are multiple ways of installing Hana on Linux.

### Flatpak
You can get Hana from Flathub:
```bash
flatpak install flathub com.hanassh.desktop
```

## Windows
Hana is available in [Microsoft Store](https://apps.microsoft.com/). Alternatively, you can download the installer from the [Downloads](https://hanassh.com/download) page.
