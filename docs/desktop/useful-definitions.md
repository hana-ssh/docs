# Useful definitions
## Data directory
Data directory is where Hana keeps most of it's files. You should only enter it if you know what you're doing as messing with any of it's contents might result in permanent data loss.

The location of the data directory differs based on platform:

## Mac
```
/Users/<username>/Library/Application Support/com.hanassh.desktop/
```

## Linux
```
???
```

## Windows
```
%appdata%/com.hanassh.desktop
```
or
```
C:\Users\<username>\AppData\Roaming\com.hanassh.desktop
```
