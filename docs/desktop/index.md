# Hana Desktop

Everything for working on servers, in one window. Hana Desktop is free, with no account required. Hosts, keys and history are kept in local vaults on your machine.

## Features

- **SFTP**: local and remote panes side by side, drag and drop, a transfer queue and conflict handling.
- **Port forwarding**: local to remote and remote to local forwards, with the bind or destination inside a Docker container. Saved tunnels live in your vault.
- **Host insights**: resource usage, logged-in users, Docker status and a process manager for the host you're on.
- **Snippets**: save the commands you run often and send them to any session.
- **Command palette**: jump to hosts, sessions and actions without leaving the keyboard.
- **Multi-exec**: type into several sessions at once.
- **Split panes & workspaces**: put terminals side by side and keep layouts as workspaces.
- **Serial & local shells**: connect to serial devices or open a local shell next to your SSH sessions.
- **Themes & keybinds**: build a theme, install one from the [theme marketplace](https://marketplace.hanassh.com/), and remap any shortcut.
