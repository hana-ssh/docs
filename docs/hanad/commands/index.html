Commands

Run commands with sudo for a system-wide hanad (the usual setup on servers), or without it for a per-user one. hanad --help and hanad <command> --help list the same information.

Command
hanad loginConnect this machine to your Hana account and start the service
hanad logoutRemove this machine from Hana and stop the service
hanad statusAccount, service, connection and SSH target state
hanad start, stop, restartControl the background service
hanad service install, uninstallRegister or unregister the service without starting it
hanad updateUpdate to the latest release
hanad telemetryTurn anonymous usage statistics on or off
hanad configRead and change settings
hanad logsPrint the daemon log
hanad uninstallLog out and remove the service (and optionally all data)
hanad runRun the daemon in the foreground

hanad login​

hanad login [--name NAME] [--no-browser] [--no-service] [--force]

Starts the device login: prints a code to approve at hanassh.com/device, registers the machine with your account once you approve, then installs and starts the background service. See Log in.

Flag
--name NAMEName shown in Hana (defaults to the hostname, at most 64 characters)
--no-browserDon't open a browser on this machine
--no-serviceDon't install or start the service; start it later with hanad start or run hanad run
--forceLog in again even if the machine is already connected; the previous host is removed from Hana

hanad logout​

Removes the host from your Hana account, deletes its credentials from the machine and stops the service. People you shared the host with lose access too. If Hana Cloud can't be reached, the credentials are still deleted; remove the host in Hana Desktop afterwards.

hanad status​

$ sudo hanad status
hanad 0.1.0 (system scope)
Account:    you@example.com
Host id:    3f2c9a4e-8b1d-4c6e-9a7f-2d5e8c1b0a93
In Hana:    "web-1", online, shared through 1 vault
Service:    running
Connection: connected to Hana Cloud
Sessions:   1 active, 14 since start
SSH target: 127.0.0.1:22 (reachable)
Telemetry:  on

--json prints the same as JSON, for scripts and monitoring. See Troubleshooting for what each state means.

Service control​

Command
hanad startStart the background service, installing it first if needed
hanad stopStop the service. The host shows as offline in Hana.
hanad restartRestart the service, e.g. after editing the config
hanad service installRegister the service (starts at boot) without starting it
hanad service uninstallUnregister the service

The service is managed by systemd or OpenRC on Linux, launchd on macOS and the Service Control Manager on Windows. It restarts automatically if hanad exits.

hanad update​

hanad update [--check]

Downloads the latest release, checks its SHA-256, replaces the running binary and restarts the service. --check only reports whether a newer version exists. See Update for automatic updates.

hanad telemetry​

hanad telemetry [on | off | status]

Turns anonymous usage statistics on or off. With no argument, or status, prints the current setting.

hanad config​

hanad config                    # print the whole config
hanad config get KEY            # print one value
hanad config set KEY VALUE      # change one value
hanad config path               # print where hanad keeps its files

Run hanad restart after changing a setting. See Configuration for the keys.

hanad logs​

hanad logs [-n LINES]

Prints the last lines of the current daemon log (100 by default). Logs rotate daily and the last 7 days are kept.

hanad uninstall​

hanad uninstall [--purge]

Logs out (removing the host from Hana), stops and unregisters the service. --purge also deletes the config, state and logs. The binary itself stays; the command prints its path so you can delete it.

hanad run​

Runs the daemon in the foreground and logs to the terminal. This is what the service runs. Useful for debugging, or in a container where a process supervisor or the container runtime keeps it running instead of a system service. Stop it with Ctrl+C.
