Install hanad

  • Linux and macOS
  • Windows
curl -fsSL https://hanassh.com/hanad.sh | sh

The installer:

  1. Picks the build for your OS and CPU and downloads it from the latest GitLab Release.
  2. Checks its SHA-256 against the release's SHA256SUMS and stops on a mismatch.
  3. Installs it to /usr/local/bin/hanad, using sudo when you aren't root. Without sudo it installs to ~/.local/bin/hanad instead.
  4. Asks whether to send anonymous usage statistics (default: yes).

It works with curl or wget, and sha256sum or shasum.

In an elevated (Run as administrator) PowerShell:

irm https://hanassh.com/hanad.ps1 | iex

The installer downloads hanad-windows-x86_64.exe from the latest GitLab Release, checks its SHA-256, installs it to C:\Program Files\hanad\hanad.exe, adds that folder to the system PATH and asks about anonymous usage statistics (default: yes). Open a new terminal afterwards so the new PATH applies.

Then log in:

sudo hanad login

Read the script first​

hanassh.com/hanad.sh and hanassh.com/hanad.ps1 serve the install.sh and install.ps1 of the latest hanad release. Open one in a browser to read it, or download it and run it yourself:

curl -fsSL https://hanassh.com/hanad.sh -o install.sh
less install.sh
sh install.sh
URLServes
hanassh.com/hanad.shinstall.sh (Linux, macOS)
hanassh.com/hanad.ps1install.ps1 (Windows)

Installer options​

Set these environment variables to change what the installer does.

VariableDefault
HANAD_VERSIONlatestInstall a specific version, e.g. 0.2.0
HANAD_TELEMETRYask1 or 0: answer the usage statistics question without a prompt
HANAD_INSTALL_DIR/usr/local/binWhere to put the binary (Linux and macOS). Setting it skips sudo.

With curl | sh the variables go on the sh side of the pipe:

  • Linux and macOS
  • Windows
# Pin a version and skip the question (e.g. in cloud-init or Ansible)
curl -fsSL https://hanassh.com/hanad.sh | HANAD_VERSION=0.2.0 HANAD_TELEMETRY=0 sh

# Install for the current user only, without sudo
curl -fsSL https://hanassh.com/hanad.sh | HANAD_INSTALL_DIR="$HOME/.local/bin" sh
$env:HANAD_VERSION = "0.2.0"; $env:HANAD_TELEMETRY = "0"
irm https://hanassh.com/hanad.ps1 | iex

Install manually​

Every release has one binary per platform, plus SHA256SUMS:

AssetPlatform
hanad-linux-x86_64Linux x86_64 (static, any distribution)
hanad-linux-aarch64Linux ARM64 (static, any distribution)
hanad-macos-x86_64macOS on Intel
hanad-macos-aarch64macOS on Apple silicon
hanad-windows-x86_64.exeWindows x86_64

The latest release's assets are always at https://gitlab.com/hanassh/hanad/-/releases/permalink/latest/downloads/<asset>:

base=https://gitlab.com/hanassh/hanad/-/releases/permalink/latest/downloads
curl -fsSLO "$base/hanad-linux-x86_64"
curl -fsSLO "$base/SHA256SUMS"
sha256sum --check --ignore-missing SHA256SUMS
sudo install -m 755 hanad-linux-x86_64 /usr/local/bin/hanad

Update​

sudo hanad update          # download, verify and install the latest release, then restart the service
sudo hanad update --check  # only report whether a newer version exists

Running the installer again also upgrades hanad and restarts a running service. To have hanad update itself, turn on auto_update (checked once a day; not available on Windows):

sudo hanad config set auto_update true
sudo hanad restart

Uninstall​

sudo hanad uninstall          # remove this machine from Hana, stop and remove the service
sudo hanad uninstall --purge  # also delete the config, state and logs
sudo rm /usr/local/bin/hanad

hanad uninstall prints where the binary is so you can delete it. On Windows, delete C:\Program Files\hanad and remove it from the system PATH.
