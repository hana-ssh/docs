# Agent

Describe the task. The agent runs commands in the session you pick, reads the output and keeps going until it is done.

- Handles interactive prompts and full-screen TUIs.
- Trims long command output before it reaches the model.
- Bring your own key: Anthropic, OpenAI, Google, xAI, Ollama and more.
- Connect MCP servers for extra tools.
